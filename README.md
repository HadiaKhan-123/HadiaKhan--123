## 🔧 What I've Built

### [Instagram Comment-to-DM Automation](https://github.com/HadiaKhan-123/instagram-comment-to-dm)
A fully automated pipeline that detects keyword comments on Instagram posts and fires a public reply + private DM — zero manual intervention, 24/7.

- Built on **n8n** (self-hosted, Node.js v24) with a two-node webhook architecture
- Integrated **Meta Graph API** + **Instagram Platform API** with OAuth 2.0 — from scratch, after Meta's 2024 API overhaul made every existing tutorial outdated
- Used **ngrok** as a reverse proxy to expose localhost to Meta's servers
- Connected **ManyChat** for DM delivery
- Navigated deeply nested JSON webhook payloads to extract the right data
- Prepared full Meta App Review package for production

**Result:** Comment reply + DM delivery live and working end-to-end.
